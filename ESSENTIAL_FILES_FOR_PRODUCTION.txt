ESSENTIAL FILES AND FOLDERS FOR PRODUCTION BRANCH

This document lists all required files/folders for the Music Performance Analysis system.

CORE PIPELINE FILES

MusicPerformanceAnalysis/
  pipeline.py                           Main pipeline (DTW-only, backward compatible)
  pipeline_with_pqg.py                  Enhanced pipeline with PQG-A2SA integration
  __init__.py                           Package initialization

LAYER 1: INPUT STANDARDIZATION

MusicPerformanceAnalysis/layers/01_input/
  input_layer.py                        Audio and score validation and standardization
  __init__.py

LAYER 2: AUDIO PROCESSING (OPTIONAL)

MusicPerformanceAnalysis/layers/02_processing/
  processing_layer.py                   Audio denoising, normalization (can be skipped)
  __init__.py

LAYER 3: TEMPORAL ALIGNMENT

MusicPerformanceAnalysis/layers/03_temporal_alignment/
  block_0_scoregraph/
    generate_scoregraph.py              Convert MusicXML to ScoreGraph JSON
  
  block_1_amt/
    amt_transcribe.py                   Audio-to-MIDI transcription using BasicPitch
  
  block_2_alignment_grading/
    context_alignment_dag.py            DTW-based score-to-performance alignment
    grading_metrics.py                  Compute grading metrics from alignment
  
  block_4_beats/
    estimate_beats_beatnet.py           Beat detection (optional, can fail gracefully)

LAYER 4: FEATURE EXTRACTION

MusicPerformanceAnalysis/layers/04_extraction/
  extraction_layer.py                   Extract performance and score features
  requirements_extraction.py            Dependencies for extraction
  __init__.py

LAYER 5: PQG-A2SA ALIGNMENT (ENHANCED PIPELINE ONLY)

MusicPerformanceAnalysis/layers/05_pqg_a2sa/
  src/
    __init__.py                         Package initialization
    config.py                           Configuration and parameters
    features.py                         Feature extraction for PQG
    nmf.py                              Non-negative matrix factorization
    vidtw.py                            Variable-length DTW
    ioi_gm.py                           Inter-onset interval Gaussian model
    baseline_dtw.py                     Baseline DTW implementation
    articulation.py                     Articulation detection
    evaluation.py                       Evaluation metrics
    pipeline.py                         PQGAligner main class (note: conflicts with main pipeline.py name)
  
  evaluate_bach10.py                    Evaluation script
  compare_algorithms.py                 Algorithm comparison utilities

LAYER 6: ENHANCED INFERENCE CORE

MusicPerformanceAnalysis/layers/06_inference/
  __init__.py                           Package exports
  inference_core.py                     Original inference core (DTW-only)
  inference_core_with_pqg.py            Enhanced inference with PQG integration
  data_collector.py                     Collects data from all layers
  pqg_metrics_recomputer.py             Recomputes metrics using PQG timings
  
  analyzers/
    __init__.py
    rhythm_tempo.py                     Rhythm and tempo analysis
    sound_quality.py                    Pitch and tone analysis
    technical_virtuosity.py             Note accuracy and fluency analysis
    phrasing_diction.py                 Phrasing and expression analysis
    communicativeness.py                Musical communication analysis
  
  utils/
    __init__.py
    metrics_extractor.py                Extract metrics from alignments
    scoring_functions.py                Score dimensions on 0-100 scale
    data_utils.py                       Data manipulation utilities
    metric_utils.py                     Metric calculation utilities

LAYER 7: GRADING

MusicPerformanceAnalysis/layers/07_grading/
  grading_layer.py                      Final grade calculation and reporting
  __init__.py

EXECUTION SCRIPTS

run_analysis.sh                         Batch processing script for DTW-only pipeline
run_analysis_with_pqg.sh                Batch processing script for PQG-enhanced pipeline
run_diesonne_with_pqg.sh                Example: DieSonne dataset with PQG

NOTES

1. Layer 2 (processing) is optional and often skipped in production.

2. Layer 5 (PQG-A2SA) is only needed for enhanced pipeline. DTW-only pipeline skips this entirely.

3. Beat detection (block 4) can fail gracefully. Pipeline continues without it.

4. Output directories are created automatically at runtime. Do not include in repository.

5. The naming inconsistency (05_inference_core should be 06_inference_core) exists in current code. This is a known issue but doesn't affect functionality.

6. PQG-A2SA's src/pipeline.py conflicts with main pipeline.py name. Import carefully using package imports.

7. For clean production branch, keep only essential documentation and remove all experimental/comparison/evaluation files unless specifically needed.
