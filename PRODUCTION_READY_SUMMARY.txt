HOW TO CREATE PRODUCTION BRANCH

Step 1: Run the setup script
```
./setup_production_branch.sh
```

This will:
- Create production branch
- Stage all necessary files
- Remove development files
- Show git status for review

Step 2: Review the staged changes
```
git status
```

Check that:
- All necessary files are staged (green)
- Development files are removed (red with "deleted:")
- No unwanted files are included

Step 3: Commit the production branch
```
git commit -m "Production release with PQG-A2SA integration"
```

Step 4: Verify before pushing
```
./verify_production_branch.sh
```

This will check:
- All essential files present
- No unwanted files included
- Python imports work

Step 5: Push to remote
```
git push origin production
```

TESTING THE PRODUCTION BRANCH

After pushing, test by cloning fresh:

```

# Enter directory

# Install dependencies

# Run quick test

  --audio Bach_10_Dataset/DieSonne/06-DieSonne-violin.wav \
  --score Bach_10_Dataset/DieSonne/06-DieSonne.xml \
```
