VISUALIZATION TYPES CREATED
============================

1. pitch_over_time.png (392KB typical)
   - Pitch timeline with note names on Y-axis
   - Blue bars = expected notes from score
   - Red line = actual performed pitches
   - Color-coded dots = individual note accuracy
   - Shows patterns over time (drift, consistency, problem sections)

2. note_errors.png (185KB typical)
   - Bar chart of individual note errors in cents
   - Color-coded by accuracy level
   - Positive bars = sharp (too high)
   - Negative bars = flat (too low)
   - Easy to identify which specific notes need work

3. accuracy_summary.png (221KB typical)
   - Pie chart showing accuracy distribution
   - Key statistics (mean error, measurement rate, percentages)
   - Overall assessment (EXCELLENT/GOOD/NEEDS WORK)
   - Quick at-a-glance performance summary

4. error_distribution.png (148KB typical)
   - Histogram of pitch errors
   - Shows error patterns (systematic bias vs. random)
   - Mean and median error lines
   - Reveals consistency and tendencies

From Block_3_PitchEvaluation directory:

To create visualizations for a single evaluation:
    python3 musician_visualizer.py <path_to_evaluation_dir>

Example:
    python3 musician_visualizer.py \
        ../../Data_Pitch/pitch_results_movement1/segment10/pitch_evaluation_20251103_062920/


TECHNICAL DETAILS
=================

Dependencies:
- matplotlib (plotting library)
- seaborn (styling)
- numpy (numerical operations)
- json (data loading)

Conversion Functions:
- freq_to_midi(freq_hz): Converts Hz to MIDI number (69 = A4 = 440Hz)
- midi_to_note_name(midi_num): Converts MIDI to note name (69 = "A4")
- get_error_color(cents_error): Returns color based on accuracy

Color Scheme:
- Green (#2ecc71): Perfect (<10 cents)
- Orange (#f39c12): Good (10-25 cents)
- Dark Orange (#e67e22): Acceptable (25-50 cents)
- Red (#e74c3c): Poor (≥50 cents)
