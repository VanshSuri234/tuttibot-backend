USAGE WORKFLOW
================================================================================

STEP 1: Run Evaluation
-----------------------
python evaluate_pitch.py --score piece.xml --audio recording.wav

Output folder created with timestamp:
pitch_evaluation_20251103_HHMMSS/


STEP 2: Check Overall Results
------------------------------
Open: MUSICIAN_REPORT.txt (in output folder)
Look at:
  - Accuracy Score (0-100)
  - Measurement Rate (should be >80%)
  - Average Pitch Error (cents)


STEP 3: Identify Problem Areas
-------------------------------
Open: note_by_note_comparison.csv
Sort by: cents_error (largest first)
Find: Notes with highest errors
Note: onset_time to locate in recording


STEP 4: Understand Details (if needed)
---------------------------------------
Read: EVALUATION_SUMMARY.txt
Check: Systematic bias, statistics
Review: PITCH_EVALUATION_DOCUMENTATION.txt for formula explanations


================================================================================
KEY CONCEPTS
================================================================================

Cents: Unit for measuring pitch deviation
   - 100 cents = 1 semitone (one piano key)
   - 10 cents = just noticeable
   - 0 cents = perfect

MACE: Mean Absolute Cents Error
   - Average of all pitch errors
   - Primary metric for accuracy
   - Lower is better

Measurement Rate: Percentage of notes detected
   - Should be >80% for reliable results
   - Low rate indicates audio quality issues

Systematic Bias: Tendency to play sharp or flat
   - Detected when average error >10 cents
   - Indicates tuning or transposition issue


================================================================================
SYSTEM CAPABILITIES
================================================================================

INPUTS:
- Score: MusicXML (.xml, .mxl) or MIDI (.mid)
- Audio: WAV, MP3, FLAC, OGG

OUTPUTS:
- Accuracy score (0-100)
- Per-note cents deviation
- Statistical analysis
- Error categorization
- Bias detection
- Visual plots (optional)

PROCESSING:
- Automatic note extraction
- Frame-by-frame pitch detection
- Temporal alignment
- Statistical computation
- Report generation

REQUIREMENTS:
- Python 3.7+
- CPU only (no GPU needed)
- ~30-60 seconds per minute of audio


================================================================================
SUPPORT AND TROUBLESHOOTING
================================================================================

Common Issues:

"Low measurement rate (<50%)"
   → Check: Audio file matches score?
   → Verify: Recording is not silent/quiet
   → Action: See QUICK_REFERENCE.txt

"High MACE (>100 cents)"
   → Check: Audio in same key as score?
   → Verify: Instrument tuned correctly?
   → Action: See Troubleshooting in QUICK_REFERENCE.txt

"Missing notes in CSV"
   → Normal for quiet/short notes
   → Check: Audio volume sufficient?
   → Review: Measurement rate

For detailed troubleshooting:
→ QUICK_REFERENCE.txt (Troubleshooting section)
→ PITCH_EVALUATION_DOCUMENTATION.txt (FAQ section)
