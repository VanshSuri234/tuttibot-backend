🎯 ALGORITHM FLOW
──────────────────
1. Extract Audio Features    → CQT chroma (23ms hop)
2. Parse Score               → Chords + instrument notes
3. VIDTW                     → Coarse chord alignment
4. IOI-GM                    → Refine tempo deviations
5. Score-Informed NMF        → Per-instrument activations
6. Articulation Refinement   → Note-level onset/offset

🔧 KEY PARAMETERS (config.py)
───────────────────────────────
HOP_LENGTH = 1024         # ~23ms audio frames
K_CL = 10                 # Clusters per chord
IOI_DELTA = 4             # ±chords for local velocity
R_LOW/HIGH = 0.6/1.67     # Deviation thresholds
NMF_ITERATIONS = 150      # NMF updates
ONSET_TOL_MS = 150        # H init onset window
OFFSET_TOL_MS = 200       # H init offset window
K_REST = 0.15             # Rest detection
K_OFF/ON = 0.65/0.2       # Staccato thresholds
T_S_MS/T_L_MS = 150/30    # Articulation windows
