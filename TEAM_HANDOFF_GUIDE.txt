1. CLONE THE BRANCH
-------------------
```bash
git clone -b Integration-Ready-Branch https://github.com/nikhilsingh-parihar/Workspace.git

```

Or if you already have the repo:
```bash
git fetch origin
git checkout Integration-Ready-Branch
```

2. RUN THE PIPELINE
-------------------
```bash
./run_analysis.sh Bach_10_Dataset/04_ChristeDuBeistand
```

This will:
- Analyze all 4 instruments (violin, clarinet, saxophone, bassoon)
- Generate alignment results
- Compute performance grades
- Save all outputs to: Output/analysis_results/04_ChristeDuBeistand/

3. OUTPUT STRUCTURE (FOR LLM CONSUMPTION)
-----------------------------------------
After running, you'll find for each instrument:

Output/analysis_results/<piece_name>/<instrument>/
├── 01_input/                  # Validated inputs
├── 02_processing/             # Processed audio
├── 03_temporal_alignment/     # CORE ALIGNMENT DATA
│   ├── scoregraph.json           ← Score structure
│   ├── transcription.json        ← Detected notes
│   ├── beats.json                ← Beat positions
│   └── alignment_output/
│       ├── alignment_results.json        ← DTW alignment (KEY FILE)
│       └── enhanced_alignment_complete.json  ← Note-level matches (KEY FILE)
├── 04_extraction/             # Extracted features
├── 05_pqg_a2sa/              # Precise alignment
├── 06_inference/             # Computed metrics
│   └── grading_package_master.json  ← ALL METRICS COMBINED (KEY FILE)
└── 07_grading/               # FINAL RESULTS
    ├── final_grade.json         ← Numeric score (KEY FILE)
    └── performance_report.txt   ← Human-readable report (KEY FILE)

4. KEY FILES FOR LLM ANALYSIS
------------------------------
Feed these JSON files to your LLM for further analysis:

PRIMARY FILES (most important):
1. 07_grading/final_grade.json
   - Overall performance score
   - Component breakdowns (pitch, rhythm, tempo, etc.)
   
2. 06_inference/grading_package_master.json
   - Complete metrics from all pipeline layers
   - Alignment statistics
   - Feature analysis
   
3. 03_temporal_alignment/alignment_output/enhanced_alignment_complete.json
   - Note-by-note alignment details
   - Onset errors, pitch errors
   - Structural labels (phrases, cadences, fermatas)

SECONDARY FILES (for deeper analysis):
4. 03_temporal_alignment/scoregraph.json
   - Score structure and metadata
   
5. 03_temporal_alignment/transcription.json
   - Transcribed performance notes
   
6. 07_grading/performance_report.txt
   - Human-readable summary

================================================================================
PIPELINE ARCHITECTURE
================================================================================

run_analysis.sh
    ↓
    ├─→ Finds all instrument audio files
    ├─→ Converts MIDI to MusicXML if needed
    └─→ For each instrument:
            ↓
        pipeline.py
            ↓
            ├─→ Layer 1: Input Standardization
            ├─→ Layer 2: Audio Processing
            ├─→ Layer 3: Temporal Alignment
            │       ├─→ Block 0: ScoreGraph generation
            │       ├─→ Block 1: Audio transcription
            │       ├─→ Block 4: Beat detection
            │       ├─→ Context Aligner (structural)
            │       └─→ Block 2: DTW alignment
            ├─→ Layer 4: Feature Extraction (parallel)
            ├─→ Layer 5: PQG-A2SA (parallel)
            ├─→ Layer 6: Inference Core
            └─→ Layer 7: Grading
                    ↓
                OUTPUT:
                - final_grade.json
                - performance_report.txt
                - grading_package_master.json
                - alignment results
                - all intermediate data

================================================================================
LLM INTEGRATION WORKFLOW
================================================================================

RECOMMENDED APPROACH:

1. RUN PIPELINE
   ```bash
   ./run_analysis.sh Bach_10_Dataset/<piece_name>
   ```

2. COLLECT OUTPUT FOR LLM
   ```python
   import json
   from pathlib import Path
   
   piece = "04_ChristeDuBeistand"
   instrument = "violin"
   base_path = Path(f"Output/analysis_results/{piece}/{instrument}")
   
   # Load key files
   with open(base_path / "07_grading/final_grade.json") as f:
       grade = json.load(f)
   
   with open(base_path / "06_inference/grading_package_master.json") as f:
       metrics = json.load(f)
   
   with open(base_path / "03_temporal_alignment/alignment_output/enhanced_alignment_complete.json") as f:
       alignment = json.load(f)
   
   # Send to LLM
   llm_input = {
       "grade": grade,
       "metrics": metrics,
       "alignment": alignment
   }
   ```

3. LLM PROMPT EXAMPLE
   ```
   You are a music performance expert. Analyze this performance data
   and provide detailed feedback:
   
   Performance Grade: {grade['overall_score']}/100
   
   Metrics:
   {json.dumps(metrics, indent=2)}
   
   Please provide:
   1. Overall assessment
   2. Strengths and weaknesses
   3. Specific improvement suggestions
   4. Practice recommendations
   ```

4. LLM OUTPUT
   - Detailed feedback text
   - Actionable recommendations
   - Area-specific coaching
