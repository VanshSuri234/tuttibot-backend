================================================================================
INTEGRATION-READY-BRANCH - FILE DEPENDENCY LIST
================================================================================

This document lists all files that will be included in the Integration-Ready-Branch.
These are the minimum required files for the run_analysis.sh pipeline to function.

================================================================================
CORE PIPELINE FILES
================================================================================

1. run_analysis.sh
   - Main entry point script
   - Orchestrates the entire analysis pipeline
   - Calls pipeline.py for each instrument

2. MusicPerformanceAnalysis/pipeline.py
   - Main Python pipeline orchestrator
   - Imports all layers and coordinates execution
   - Entry point: main() function
